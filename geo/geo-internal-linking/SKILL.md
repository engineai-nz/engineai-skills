# Geo Internal Linking

Build internal linking architecture.

## Process

1. Map site pages and content types
2. Identify linking opportunities
3. Create hub-and-spoke structures
4. Write contextual anchor text
5. Define linking rules

## Linking Principles

- Every page should be reachable in 3 clicks from homepage
- Related content should be cross-linked
- Anchor text should be descriptive, not generic
- New content should link to existing relevant pages
- Existing pages should be updated to link to new content

## Output

- Internal linking map
- Hub page recommendations
- Anchor text guidelines
- Linking rules for future content
