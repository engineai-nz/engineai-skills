# Geo Schema

Generate and validate schema markup for rich results and AI understanding.

## Process

1. Identify the content type (article, FAQ, product, organization, local business)
2. Select appropriate schema types
3. Generate JSON-LD markup
4. Validate against schema.org spec
5. Check for required and recommended properties

## Output

- JSON-LD schema markup ready to implement
- Validation notes
- Additional schema opportunities
