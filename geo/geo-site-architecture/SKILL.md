# Geo Site Architecture

Plan information architecture for crawlability and user experience.

## Process

1. Audit current site structure (if existing)
2. Define content categories and hierarchy
3. Plan URL structure
4. Design navigation (primary, secondary, footer)
5. Create XML sitemap structure
6. Plan internal linking between sections

## Output

- Site architecture diagram (text-based)
- URL structure recommendations
- Navigation plan
- XML sitemap outline
